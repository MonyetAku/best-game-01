Mango Rush — Monyet's Canopy Dash: an original 2D canvas jungle game. A monkey runs, jumps and dashes through the canopy, dodging falling coconuts, catching mangoes, and outrunning swooping eagles. Three lives, combo multipliers up to ×5, levels every 18 seconds, and a 400-point Golden Mango win goal. Keyboard and mouse controls, synthesized WebAudio sounds, all art drawn in code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
